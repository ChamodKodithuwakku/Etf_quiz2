Q11Structured

What is AJAX? Explain how it makes web pages more responsive, and list three things you can do with it.

Show model answerHide model answer

AJAX (Asynchronous JavaScript And XML) is not a programming language. It is a development technique for creating interactive web applications. It uses JavaScript to send and receive data between a web browser and a web server.

It makes pages more responsive by exchanging data with the server behind the scenes, instead of reloading the entire page each time the user makes a change.

  • Read data from a web server after the page has loaded
  • Update a web page without reloading the page
  • Send data to a web server in the background

Q15Structured

This code should show the contents of info.txt when the button is clicked, but nothing appears. Find the bug, fix it and say what will be displayed.

<div id="display">
  <button type="button" onclick="loadDoc()">Load</button>
</div>
<script>
function loadDoc() {
  var xhttp = new XMLHttpRequest();
  xhttp.onreadystatechange = function() {
    if (this.readyState == 4 && this.status == 200) {
      document.getElementById("demo").innerHTML = this.responseText;
    }
  };
  xhttp.open("GET", "info.txt", true);
  xhttp.send();
}
</script>
Show model answerHide model answer
  • The callback writes to document.getElementById("demo"), but no element has id="demo". The div's id is display.
  • getElementById("demo") returns null, so setting .innerHTML throws a TypeError and nothing changes.

Fix: use document.getElementById("display"), or rename the div to id="demo".

When readyState == 4 and status == 200, the div shows the contents of info.txt: a heading “Hello from AJAX” and the paragraph “I am flexible and dynamic”.

Q17Structured

Explain the XMLHttpRequest properties onload, onreadystatechange, readyState (all values), status, responseText/responseXML and statusText.

Show model answerHide model answer
  • onload: the function called when the request has been received (loaded).
  • onreadystatechange: the function called every time readyState changes.
  • readyState: the status of the request. 0 = uninitialized, 1 = loading, 2 = loaded, 3 = interactive (some data returned), 4 = complete.
  • status: the HTTP status returned by the server, e.g. 200 "OK", 403 "Forbidden", 404 "Not Found".
  • responseText: the response as a string. responseXML: the response as XML data.
  • statusText: the status text, e.g. "OK" or "Not Found".
Q18Structured

Write jQuery code that loads load.txt into #dis when the button is clicked and shows an alert for success or error. Explain the three callback parameters.

Show model answerHide model answer 
$(document).ready(function(){
  $("button").click(function(){
    $("#dis").load("load.txt", function(responseTxt, statusTxt, xhr){
      if (statusTxt == "success")
        alert("External content loaded successfully!");
      if (statusTxt == "error")
        alert("Error: " + xhr.status + ": " + xhr.statusText);
    });
  });
});
  • responseTxt contains the resulting content if the call succeeds.
  • statusTxt contains the status of the call ("success" or "error").
  • xhr contains the XMLHttpRequest object.
Q19Structured

Using $.getJSON(), write jQuery code that reads simpleObject.json (below) and shows its id, name and gender in #dis when the button is clicked.

{ "id": 1, "name": "Adnan", "gender": "male" }
Show model answerHide model answer 
$(document).ready(function(){
  $("button").click(function(){
    $.getJSON('simpleObject.json', function(data) {
      $('#dis').html('<p>ID: ' + data.id + '</p>');
      $('#dis').append('<p>Name: ' + data.name + '</p>');
      $('#dis').append('<p>Gender: ' + data.gender + '</p>');
    });
  });
});

getJSON(URL, [data], [callback]) parses the returned JSON, so data is already an object. .html() replaces the content and .append() adds to it.

Q20Structured

Write a $.ajax() call that requests simpleObject.json as JSON with a 500 ms timeout. On success it appends the data to #demo; on failure it appends an error message. Give the syntax of $.ajax() and name the HTTP methods it can send.

Show model answerHide model answer 
$('#ajaxBtn').click(function () {
  $.ajax('simpleObject.json', {
    dataType: 'json',           // type of response data
    timeout: 500,               // milliseconds
    success: function (data, status, xhr) {
      $('#demo').append(data.id + ' ' + data.name + ' ' + data.gender);
    },
    error: function (jqXhr, textStatus, errorMessage) {
      $('#demo').append('Error: ' + errorMessage);
    }
  });
});
  • Syntax: $.ajax(url) or $.ajax(url, [options]). The options parameter customises the request.
  • $.ajax() provides the core AJAX functionality of jQuery. It sends asynchronous HTTP requests and can send GET, POST, PUT, DELETE and other requests.
