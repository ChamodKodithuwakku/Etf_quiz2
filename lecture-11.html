Q12Structured

Show model answerHide model answer

REPL = Read, Evaluate, Print, Loop. The user enters a JavaScript command, Node evaluates it, prints the result and loops back for another command.

  • Supports multi-line commands
  • Customisable command prompt and pre-configured context
  • Sessions can be saved and reloaded
  • Useful for learning JavaScript or running tasks from a JavaScript command line

Q14Structured

Explain each line of this Node.js program and state what happens when it runs.

var http = require('http');

http.createServer(function (req, res) {
    res.writeHead(200, {'Content-Type': 'text/plain'});
    res.end('Hello World!');
}).listen(8080);
Show model answerHide model answer
  • require('http') imports Node's built-in http module.
  • http.createServer(function (req, res) {...}) creates an HTTP server. The function runs for every request, with req the request and res the response.
  • res.writeHead(200, {'Content-Type': 'text/plain'}) sends status 200 (OK) and a plain-text content type.
  • res.end('Hello World!') sends the body and ends the response.
  • .listen(8080) makes the server listen on port 8080.

Result: opening http://localhost:8080 in a browser shows “Hello World!”.

Q16Structured

Explain what this Express setup code does.

var express = require("express");
const bodyParser = require('body-parser');
const cors = require('cors');

var app = express();
app.use(cors());
app.use(bodyParser.urlencoded({ extended: false }));
app.use(bodyParser.json());

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
Show model answerHide model answer
  • Imports express (the web framework), body-parser (parses request bodies) and cors (middleware for Cross-Origin Resource Sharing).
  • var app = express() creates the Express application.
  • app.use(cors()) allows requests from other domains.
  • bodyParser.urlencoded({ extended: false }) parses URL-encoded (form) bodies, and bodyParser.json() parses JSON bodies into req.body.
  • app.listen(3000, ...) starts the server on port 3000 and logs “Server running on port 3000”.
Q17Structured

Explain the filter() array method and its syntax. What does students.filter((x) => x.id == sid)[0] return when (a) a match exists and (b) no match exists?

Show model answerHide model answer 
array.filter(function(currentValue, index, arr), thisValue)

filter() creates a new array with only the elements that pass the test function. It does not change the original array.

  • (a) A match exists: [0] returns the first student object whose id equals sid.
  • (b) No match: filter() returns an empty array, so [0] is undefined. The route treats this as falsy and sends 404.

Example: [32, 33, 12, 40].filter(age => age > 30) gives [32, 33, 40].

Q18Structured

Write Express route handlers for (a) GET /students, which returns all students as JSON, and (b) GET /student/:id, which returns one student or status 404 if not found.

Show model answerHide model answer 
let students = [{"id":1, "name":"Nimal", "Address":"Malabe"}];

app.get("/students", (req, res) => {
  res.json(students);
});

app.get("/student/:id", (req, res) => {
  let sid = parseInt(req.params.id);
  let tempStu = students.filter((x) => x.id == sid)[0];
  if (tempStu) {
    res.json(tempStu);
  } else {
    res.sendStatus(404);
  }
});
Q19Structured

Write Express route handlers to (a) add a new student with POST /student and (b) update a student's name and Address with PUT /student/:id, responding 200 if updated and 404 if not found.

Show model answerHide model answer 
// (a) Insert
app.post("/student", (req, res) => {
  const newstudent = req.body;
  students.push(newstudent);
  res.send('Student is added to the list');
});

// (b) Update
app.put("/student/:id", (req, res) => {
  let sid = parseInt(req.params.id);
  let stu = req.body;
  let tempStu = students.filter((x) => x.id === sid)[0];
  if (tempStu) {
    tempStu.name = stu.name;
    tempStu.Address = stu.Address;
    res.sendStatus(200);
  } else {
    res.sendStatus(404);
  }
});

req.body is available because body-parser was registered.

Q20Structured

Write jQuery $.ajax() code for the UI that sends a new student (id, name and address from the text boxes #SId, #SName and #SAddress) to POST /student. Why is JSON.stringify() used? Name a tool that can test the API without a UI.

Show model answerHide model answer 
$.ajax({
  type: 'POST',
  url: 'http://localhost:3000/student/',
  contentType: 'application/json',
  data: JSON.stringify({
    "id": $('#SId').val(),
    "name": $('#SName').val(),
    "address": $('#SAddress').val()
  }),
  success: function (data, textStatus, jQxhr) {
    alert("Data Inserted");
  },
  error: function (xhr, textStatus, error) {
    alert("Error");
  }
});
  • JSON.stringify() converts the JavaScript object into a JSON string, because data sent to or received from a web server is always a string. With contentType: 'application/json', body-parser on the server turns it back into an object (req.body). On the client, JSON.parse() converts received strings into objects.
  • Postman can test the API without a UI.
