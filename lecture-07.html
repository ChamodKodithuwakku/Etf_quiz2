Q5Multiple choice

Which container class gives a full-width container spanning the entire width of the viewport?

Correct!

Not quite. The correct answer is B.

.container is a responsive fixed-width container. .container-fluid spans the full width of the viewport. Containers are not nestable.

Q6Multiple choice

The Bootstrap grid system allows up to how many columns across the page?

Correct!

Not quite. The correct answer is A.

The grid allows up to 12 columns. In each row, the numbers in the .col-*-* classes should add up to 12.

Q11Structured

Define responsive web design. What is Bootstrap, and what does it provide to help build responsive web sites?

Show model answerHide model answer

Responsive web design means creating web sites that automatically adjust themselves to look good on all devices, from small phones to large desktops.

Bootstrap is a free, open-source front-end framework (HTML, CSS and JavaScript) for faster and easier, mobile-first web development. It provides:

  • HTML- and CSS-based design templates for typography, forms, buttons, tables, navigation, modals, image carousels and more
  • Optional JavaScript plugins
  • A responsive 12-column grid system, so layouts re-arrange automatically for different screen sizes
Q12Structured

Briefly describe the history of Bootstrap and list its four main advantages.

Show model answerHide model answer

Bootstrap was developed by Mark Otto and Jacob Thornton at Twitter and released as an open-source product on GitHub in August 2011. Bootstrap 5 is the newest version. It adds new components, faster stylesheets and more responsiveness, and it uses JavaScript instead of jQuery.

Main advantages:

  • Easy to use
  • Responsive features
  • Mobile-first approach
  • Browser compatibility
Q13Structured

Describe the two ways to start using Bootstrap on a web site, and explain two advantages of using a CDN.

Show model answerHide model answer
  • Download Bootstrap from getbootstrap.com and host it yourself.
  • Include it from a CDN (Content Delivery Network) such as MaxCDN by linking its CSS and JavaScript files. Older versions also need jQuery.

Advantages of a CDN:

  • Many users have already downloaded Bootstrap from the CDN on other sites, so the browser loads it from cache, which makes loading faster.
  • The CDN serves the file from the server closest to the user, which also makes loading faster.
Q14Structured

Write the viewport <meta> tag used in Bootstrap pages. Explain why it is needed and what each part of its content attribute does.

Show model answerHide model answer 
<meta name="viewport" content="width=device-width, initial-scale=1">
  • Bootstrap is mobile-first. Put this tag inside <head> to ensure proper rendering and touch zooming on mobile devices.
  • width=device-width sets the width of the page to follow the screen width of the device.
  • initial-scale=1 sets the initial zoom level when the page is first loaded by the browser.
Q15Structured

Write a complete HTML5 page that uses Bootstrap from a CDN and shows the heading “My First Bootstrap Page” inside a fixed-width container.

Show model answerHide model answer 
<!DOCTYPE html>
<html lang="en">
<head>
  <title>Bootstrap Example</title>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="https://maxcdn.bootstrapcdn.com/bootstrap/3.4.1/css/bootstrap.min.css">
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.6.1/jquery.min.js"></script>
  <script src="https://maxcdn.bootstrapcdn.com/bootstrap/3.4.1/js/bootstrap.min.js"></script>
</head>
<body>
  <div class="container">
    <h1>My First Bootstrap Page</h1>
    <p>.container is a fixed width container</p>
  </div>
</body>
</html>

Key points: the HTML5 doctype with lang and charset, the viewport meta tag, the Bootstrap CSS (plus jQuery and Bootstrap JS for v3), and the content wrapped in .container.

Q16Structured

Explain the difference between .container and .container-fluid. Can containers be nested?

Show model answerHide model answer
  • Bootstrap requires a containing element to wrap the site contents.
  • .container is a responsive fixed-width container. Its width changes at each breakpoint.
  • .container-fluid is a full-width container that spans the entire width of the viewport.
  • Containers are not nestable, so do not put one container inside another.
Q17Structured

Write Bootstrap markup for a desktop layout with one row of three equal columns. Explain why you chose those column numbers.

Show model answerHide model answer 
<div class="container">
  <div class="row">
    <div class="col-md-4">Column 1</div>
    <div class="col-md-4">Column 2</div>
    <div class="col-md-4">Column 3</div>
  </div>
</div>

First create a row (<div class="row">), then add columns with .col-*-* classes. The grid has 12 columns and the numbers in each row should add up to 12, so three equal columns are 4 + 4 + 4. md targets desktops. On smaller screens the columns stack automatically.

Q18Structured

Name the four grid classes of the Bootstrap grid system and the devices they target. How does <div class="col-sm-6 col-md-3"> behave?

Show model answerHide model answer
ClassIntended for
xsPhones
smTablets
mdDesktops
lgLarger desktops

You can combine the classes for more flexible layouts. col-sm-6 col-md-3 takes 6/12 (half the row) on tablets and 3/12 (a quarter) on desktops and larger. On phones (xs) it stacks to full width.

Q20Structured

Write HTML with Bootstrap classes to create: (a) a large, block-level success button, (b) a link styled as an info button, (c) a disabled primary button and (d) an active (pressed) danger button. Which elements can the button classes be used on?

Show model answerHide model answer 
<button type="button" class="btn btn-success btn-lg btn-block">Save</button>
<a href="#" class="btn btn-info" role="button">Link Button</a>
<button type="button" class="btn btn-primary disabled">Disabled Primary</button>
<button type="button" class="btn btn-danger active">Active Danger</button>
  • You can use the button classes on <a>, <button> and <input> elements.
  • Styles: .btn-default, .btn-primary, .btn-success, .btn-info, .btn-warning, .btn-danger, .btn-link
  • Sizes: .btn-lg, .btn-md, .btn-sm, .btn-xs
  • .active makes a button look pressed. .disabled makes it unclickable.
