Q2Multiple choice

Which built-in JavaScript function converts a JSON string into a JavaScript object?

Correct!

Not quite. The correct answer is C.

JSON.parse() turns a JSON string into an object. JSON.stringify() does the opposite.

Q3Multiple choice

What does JSON.stringify() do?

Correct!

Not quite. The correct answer is A.

JSON data is text only. stringify() produces that text so it can be sent between computers.

Q4Multiple choice

JSON is built on which two structures?

Correct!

Not quite. The correct answer is D.

Name/value pairs become an object, record, dictionary or hash table. An ordered list becomes an array, vector, list or sequence.

Q5Multiple choice

A JSON object begins and ends with…

Correct!

Not quite. The correct answer is B.

Objects use braces { }. Arrays use brackets [ ].

Q6Multiple choice

Which of these is NOT a valid JSON value?

Correct!

Not quite. The correct answer is A.

JSON strings must be in double quotes. Valid values are strings, numbers, true, false, null, objects and arrays.

Q7Multiple choice

Which of these is valid JSON?

Correct!

Not quite. The correct answer is B.

Names must be strings in double quotes, and a trailing comma is not allowed.

Q9Multiple choice

Correct!

Not quite. The correct answer is C.

eval() runs any code it is given, so use it only on authentic, trusted strings. parseJSON() is safer, while eval() is faster.

Q11Structured

Define JSON and list five characteristics that make it an ideal data-interchange language.

Show model answerHide model answer

JSON (JavaScript Object Notation) is a lightweight, text-based data-interchange format.

  • Easy for humans to read and write
  • Easy for machines to parse and generate
  • Based on a subset of the JavaScript programming language (Standard ECMA-262, 3rd Edition, December 1999)
  • A text format that is completely language independent
  • Text only, so data can easily be sent between computers and used by any programming language
Q12Structured

Explain the two structures JSON is built on. For each one, give its equivalent in other programming languages and a JSON example.

Show model answerHide model answer
  • A collection of name/value pairs. Other languages call it an object, record, dictionary, hash table, keyed list or associative array. Example: {"name":"John"}
  • An ordered list of values. Other languages call it an array, vector, list or sequence. Example: ["red", "green", "blue"]

These structures can be nested, for example an object that holds an array of objects.

Q13Structured

Describe the syntax rules for a JSON object, a JSON array, a value and a string.

Show model answerHide model answer
  • Object: an unordered set of name/value pairs. It begins with { and ends with }. Each name is followed by : and the pairs are separated by ,.
  • Array: an ordered collection of values. It begins with [ and ends with ], and values are separated by ,.
  • Value: a string in double quotes, a number, true, false, null, an object or an array. Values can be nested.
  • String: zero or more Unicode characters wrapped in double quotes, using backslash escapes. A character is a single-character string, much like a C or Java string.
Q14Structured

Show model answerHide model answer

  • 'Kamal' uses single quotes. Use double quotes: "Kamal".

  • True must be lowercase: true.

Q17Structured

Q20Structured

Discuss (a) the benefits of JSON over XML and (b) the security risk of validating JSON with eval().

Show model answerHide model answer

(a) Benefits of JSON over XML:

  • JSON supports data types such as string, integer and Boolean.
  • It is the native data format of JavaScript, so the browser reads and understands it faster. XML has to be parsed with XPath, an overhead JSON removes.
  • JSON has no tags, only data, so less data is transferred between client and server. It is lighter than XML, whose tags increase the data size.
  • It is easy for humans to read and write.

(b) eval() executes whatever JavaScript it is given, so a malicious string could run harmful code. Use eval() only when the source is authentic and trusted. When there is a security risk, use a parser such as parseJSON() from json.org/json.js. eval() is faster but less safe. In modern JavaScript, the built-in JSON.parse() is the safe choice.
