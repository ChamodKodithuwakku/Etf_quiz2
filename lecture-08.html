Q11Structured

What is jQuery? Give four reasons why developers use jQuery.

Show model answerHide model answer

jQuery is a JavaScript library, the most popular JavaScript framework. It is designed to change the way you write JavaScript and greatly simplifies JavaScript programming.

  • Write less code. What takes 20 or more lines of JavaScript can be done in two or three lines of jQuery.
  • The same code runs in all browsers.
  • It uses CSS selectors and JavaScript notation, which developers already know.
  • It is easy to learn.
  • It is widely used by companies such as Netflix, Amazon, Twitter, Dell and Best Buy.

Q14Structured

Define the Document Object Model (DOM). Draw the DOM tree for the HTML below and name the node types.

<p>
  This is a paragraph of text with a
  <a href="/path/page.html">link in it</a>.
</p>
Show model answerHide model answer

The DOM is a cross-platform, language-independent convention for representing and interacting with objects in HTML, XHTML and XML documents. A programming language such as JavaScript or jQuery can address and manipulate its parts, such as elements.

<p>                                    element node
├── "This is a paragraph of text with a "   text node
├── <a>                                element node
│   ├── href="/path/page.html"         attribute node
│   └── "link in it"                   text node
└── "."                                text node

There are three node types here: element, text and attribute nodes.

Q16Structured

What is the jQuery document ready handler, and why should jQuery code go inside it? Write both the long and short versions.

Show model answerHide model answer

The ready event occurs when the DOM has been loaded. Code inside the ready handler runs only after the document is ready, so every element exists and can be selected safely. This makes it a good place for all other jQuery events and functions. The ready() method specifies what happens when the ready event occurs.

// Long version
$(document).ready(function(){
  // jQuery code here
});

// Short version
$(function() {
  // jQuery code here
});

Q19Structured

Write jQuery code that turns <div id="myDiv"> (100×100 px, initially red) green when the mouse enters it and red again when the mouse leaves.

Show model answerHide model answer 
$(document).ready(function () {
  $('#myDiv').mouseenter(function () {
    $(this).css('background-color', 'green');
  });
  $('#myDiv').mouseleave(function () {
    $(this).css('background-color', 'red');
  });
});

mouseenter and mouseleave are mouse events, $(this) refers to the div that fired the event, and .css() changes its style.
